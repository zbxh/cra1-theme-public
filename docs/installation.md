# 酷锐A1主题手动安装图文教程

适用版本：**v17.1 测试版**。

## 01 准备安装

本教程用于把酷锐A1主题安装到已有的 V10 网站。安装后分别管理**官网、会员中心、购物车**，无需安装 Node 或自行编译。

**安装交流 QQ 群：603107399** · [点击加入 QQ 群](https://qm.qq.com/q/O3d7bVtcoS)

### 先确认这四件事

- 备份当前网站文件、数据库与配置，保存一份可恢复的副本。
- 本包使用 V10 10.7.4、PHP 7.4、Nginx；如果仍为 V10 10.7.2，先通过官方流程升级。系统及模块是否匹配，以安装向导的检查结果为准。
- 网站 HTTPS 正常，准备好 V10 **超级管理员**账号和服务器文件管理权限。
- 首次安装使用 `cra1-theme-install.zip`；已经安装主题的站点，后续使用配套**更新包**，无需卸载。

### 拿到文件以后

下载 `CRA1-theme-v17.1-install-with-guide.zip` 后，先在电脑上解压外层 ZIP。里面的 `cra1-theme-install.zip` 才是需要上传网站的安装包；“安装教程”文件夹留在电脑上阅读即可。

| 文件 | 用途 |
| --- | --- |
| cra1-theme-install.zip | 首次安装主题，上传到 V10 网站根目录 |
| 安装教程.pdf | 按页查看、打印 |
| 安装教程.html | 浏览器离线阅读，图片已嵌入 |
| nginx.example.conf | 目录保护规则示例，安装时合并到现有配置 |

> 教程中的域名、后台入口和账号均为示例，不是可用登录资料。密码区域已隐藏或遮盖；请填写自己的信息。

## 02 上传并解压安装包

在服务器面板或文件管理工具中，打开 **V10 网站根目录**，确认这里已有 `config.php`、`vendor/` 和 `public/`。上传安装 ZIP，然后在此目录解压。

![解压位置示意：主题文件与现有 V10 目录合并，不额外套一层文件夹。](images/install-guide-location.png)

- 同名目录选择合并，保留原有 V10 文件、配置与数据。安装包不包含 V10 本体、站点配置或默认后台账号。
- 解压后应出现 `cra1-theme/` 和 `public/cra1-install/` 等目录。网站的**运行目录仍指向 `public/`**。
- 让主题文件归属于本站 PHP 运行用户，文件可读，安装向导要求的私有目录可写。不要把整个站点设置成 777。

> 不要把安装包解压进 public；也不要产生“网站根目录 / 安装包名称 / public”这样的多余层级。

## 03 配置目录保护

在服务器面板中打开本站 Nginx 配置，先备份该配置。读取安装包内 `cra1-theme/docs/nginx.example.conf`，或教程旁的同名文件。

- 把示例规则合并到现有的 `server { ... }` 内；保留原 HTTPS、PHP 和 V10 路由规则。
- 将文件中的每个 `<theme-admin-entry>` 替换为计划使用的主题后台入口，例如 `a1manage`，不要带斜杠。稍后安装表单必须填写同一个入口。
- 这些正则规则要放在现有宽泛 PHP / 静态文件匹配规则之前，避免被原规则先匹配。
- 通过服务器面板检查 Nginx 配置语法，确认成功后重载服务。

> 示例文件是要合并的规则片段，不是一份可直接替换整站的 Nginx 配置。

### 执行目录保护自检

使用本站 **PHP 7.4 和 PHP 运行用户**执行以下命令。把 `/path/to/v10` 换成网站根目录，把 `https://example.com` 换成本站 HTTPS 源地址。

```bash
cd /path/to/v10
php cra1-theme/scripts/private-path-check.php \
  --root=/path/to/v10 \
  --origin=https://example.com
```

如果终端默认 PHP 不是本站 PHP 7.4，请将命令中的 `php` 换成对应 PHP 可执行文件的完整路径。自检通过后有效期为 **24 小时**，再继续打开安装向导。

自检失败时，先检查域名、HTTPS 证书、文件权限和 Nginx 规则顺序。修正后重新执行；不要跳过保护检查。

> 例如：保护规则和安装表单都使用 a1manage 时，安装后的后台地址就是 https://example.com/a1manage/。

## 04 验证管理员与环境

先在浏览器登录本站 **V10 超级管理员**账号，然后在**同一浏览器、同一域名**打开安装向导。会员账号或主题后台账号不能代替这一步。

```bash
https://example.com/cra1-install/
```

将示例域名替换为本站域名，点击 **“验证并检查”**。

![当前安装器界面示例，未连接真实站点。](images/install-guide-start.png)

### 检查后会出现什么

- 检查通过：显示“设置主题后台”表单，继续下一步。
- 有阻断项：展开明细，按提示修正环境或文件后重新检查。不要覆盖 V10 核心、默认主题或官方插件来跳过检查。
- 提示已安装：这是维护状态，应使用现有主题后台；不要重新创建账号或覆盖配置。

> 本教程截图中的检查结果来自独立演示数据。实际安装以你的网站检查结果为准。

## 05 设置主题后台并安装

填写自己的后台入口、账号和密码。**本站 HTTPS 地址只填源地址**，不带页面路径。完成后点击“安装并启用三个主题”。

![设置界面示例。账号和入口仅为说明；密码输入区域已遮盖。](images/install-guide-settings.png)

- 后台入口：6–32 位小写字母或数字，以字母开头，与 Nginx 规则一致。
- 账号：3–32 位字母、数字、下划线或连字符；密码：12–128 位，两次一致，建议使用强密码。
- 安装器会建立独立账号、密钥和配置，并启用官网、会员中心、购物车及对应手机和首页入口。

## 06 保存登录资料

安装成功后，保存页面显示的**后台地址、账号和密码**。密码只在本次流程展示，可点击“隐藏密码”；请保存到私密位置，不要把含密码的截图发到群里。

![成功界面示例：密码已隐藏，域名、账号和入口均为演示值。](images/install-guide-success.png)

- 点击“进入主题后台”，使用刚设置的主题账号登录。它与 V10 超级管理员账号独立。
- 初始化入口此后锁定。再次访问安装器进入维护状态，不会重新初始化账号或覆盖已有配置。
- 若安装失败，按界面原因处理后重试；不要通过删除站点配置或数据库来重装。

## 07 进入后台完成初始设置

从总览选择要修改的主题，再进入具体页面或公共设置。**官网、会员中心、购物车的配置独立保存**。

![主题后台总览示例；未使用真实站点数据。](images/install-guide-overview.png)

### 建议先做这几项

- 分别检查官网头部与底部、会员菜单、购物车商品展示及通知内容。
- 每个配置页修改完成后，使用该页保存按钮；需要查看草稿效果时打开“预览效果”。
- 网站名称、商品和价格等系统业务资料仍在 V10 中管理。主题后台负责页面展示。
- 打开官网、会员登录页、商品列表和购物车，确认页面正常。未登录访问受保护会员页时，应跳转登录。

> 截图中的空白配置与示例账号仅用于讲解。正式安装不会提供可共享的默认登录资料。

## 08 后续更新与回退

以后更新时，先备份站点，再登录主题后台，进入 **“主题管理 → 安装与更新”**，上传 `CRA1-theme-v17.1-update.zip`。首次安装包不能代替更新包。

![更新入口示例：侧栏“主题管理”，顶部“安装与更新”。](images/install-guide-update.png)

- 上传后查看检查结果，由主题超级管理员确认应用；按提示重新验证主题后台密码。
- 更新保留配置、账号、密钥、媒体、草稿和页面覆盖，无需卸载重装。
- 若更新中断，进入“备份与回退”恢复。成功更新后也可回退界面与资源引用，配置、业务数据及较新的安全后端保留。

V10 或模块升级后，在主题管理重新检查。若提示当前版本或依赖不匹配，使用适配的更新包，不要用旧系统文件覆盖新版 V10。

## 09 常见问题与交流

| 遇到的问题 | 处理方法 |
| --- | --- |
| 安装入口 404 | 检查解压层级是否正确；网站运行目录应为 public；确认 Nginx 规则顺序与路由未被覆盖。 |
| 提示需要管理员登录 | 在同一浏览器、同一域名先登录 V10 超级管理员，再打开安装器。 |
| 私有目录保护未通过或已过期 | 检查 HTTPS、目录权限和保护规则，重新运行第 3 步的自检命令。 |
| 填写的后台入口打不开 | 确认安装表单与 Nginx 中的入口完全一致；使用成功页给出的地址。 |
| 提示已经安装 | 使用原主题后台；更新请进入“主题管理 → 安装与更新”。不要重复初始化。 |
| 检查提示版本或文件不匹配 | 展开明细，确认系统、模块和安装包对应；获取匹配版本，不要跳过检查或覆盖系统文件。 |
| 更新失败或中断 | 按提示处理，在“备份与回退”恢复中断更新，再重新检查。 |
