CRA1 官网配置

网站菜单

控制官网桌面导航与移动端抽屉（每行：名称|链接|简介|是否新窗口，二级项在名称前加 >）。

示例：产品服务|/cart/goodsList.htm|产品与服务|0，下一行 >云服务器|/cloud.html|弹性云服务器|0。链接支持 /、https://、tel:、mailto:。「产品服务」下拉的商品列表仍实时读取商品接口。

首屏轮播

每行：图片或视频地址|链接|标题|描述|按钮文字|按钮链接。后四段可省略；按钮链接省略时使用整页链接；按钮文字为空时不显示按钮。

示例：/web/cra1/assets/img/banner/banner-hw-1.jpg|/cart/goodsList.htm|弹性计算|按需快速创建云服务器|选购云服务器|/cloud.html

首页产品

指定首页「产品与价格」模块展示的商品。每行：商品ID|排序|展示标签（标签可省略）。名称与价格仍实时读取商品接口，不在此保存价格。

商品 ID 可在「商品管理」列表查看；未配置时首页自动读取商品分组与商品。
