# CRA1 会员中心主题

会员中心保留 Vue 外壳和 React 内容区。官网、会员中心与购物车平级，分别保存内容和自定义 CSS/JS；共用层只维护公共组件、请求和安全交互。

## 源码与发布

会员正式源码位于 `cra1-theme/source/member`，共用源码位于 `public/cra1-shared/src`，后台源码位于 `cra1-theme/source/admin`。唯一发行构建入口、锁文件与暂存规则见 `cra1-theme/docs/开发与构建.md`。构建不会直接覆盖线上资源。

发行清单与私有生效指针共同选择版本。React 入口使用固定名称，共享 chunk 使用内容校验名称，整套文件放进新的不可变目录。私有后端也使用独立版本目录；一次请求固定使用同一后端实现，准备完成后才切换。

安装与更新说明见 `cra1-theme/docs/安装更新与回退.md`，兼容范围见 `cra1-theme/docs/发行支持矩阵.md`。具体支持情况以实际版本和兼容检查结果为准。

## 页面与原生回退

- 主题页面使用自身 React 组件；未知模块、系统插件保留原生业务页面。
- 原生模块脚本执行前，先加载真实的 `asideMenu`、`topMenu`、请求层与公共方法。
- `js/module-deps.js` 按依赖图装载原生组件、去重并检查真实定义；下载失败可重试，初始化失败提示刷新。
- 原生库及未改造组件由发行清单明确登记，从客户合法安装环境引用；不会修改或随包覆盖 default 与插件源文件。
- 这些依赖的版本、作用、变化影响及验收情况在主题管理中列出，不能仅因相对链接有效就认定升级兼容。

## 业务约定

产品分类来自后台导航关联产品，保留现有状态与到期时间双重过滤。菜单内部编号由接口获取，不硬编码到主题。

登录依照原生接口使用 AES；注册、找回密码依照各自原生契约提交，不能统一套用登录加密。敏感操作先保留系统鉴权、权限与归属校验，再执行主题附加验证。短信、邮件优先；否则按启用状态验证操作密码，服务端授权最多十五分钟并绑定当前登录。普通响应不返回明文凭据。

主题头像、首页产品投影和增强磁盘、流量数据从主题自有接口获取。缺失能力和未知敏感契约对前台返回通用原因，具体版本与兼容明细仅在主题后台提供。

三份主配置、账号、密钥、媒体、页面覆盖和草稿均保留在非公开运行目录。旧快照入口继续经过同一净化投影，不把关闭内容或后台配置整包下发。

## 开发与验证

保持现有页面布局和交互，基础组件从共用源码维护，主题自定义 CSS 继续可以覆盖默认样式。390px 下保持单列和足够的操作命中区；弹窗、复制、下拉和排序支持键盘。

样式及图片包含历史第三方输入，不能因修改了文档就视作原创或已获再分发授权；对应来源与许可必须完成发行核验。

隔离测试、候选门禁及官方升级证据记录说明见发行文档。不要对正式产品执行下单、支付、退订或服务器操作测试。
