# 酷锐A1主题安装、更新与回退

## 首次安装

1. 备份现有站点、数据库和配置，确认 V10 与模块版本符合安装包要求。V10 10.7.2 需先按官方流程升级至 10.7.4。
2. 将安装 ZIP 解压到 V10 网站根目录，保留目录结构。不要解压到 `public` 内；客户无需安装 Node 或运行构建。
3. 参考 `nginx.example.conf`，将私有目录保护规则合并至本站现有配置。网站运行目录仍为 `public`，保留 V10 路由和 HTTPS 配置。检查 Nginx 语法后重载。
4. 运行私有路径检查：`php cra1-theme/scripts/private-path-check.php --root=/实际站点目录 --origin=https://实际域名`。检查会清理本次临时文件，通过记录有效 24 小时。如使用自有 CA，可增加 `--ca-file=/绝对路径/CA证书.pem`。
5. 在同一浏览器登录 V10 超级管理员，访问 `https://实际域名/cra1-install/`，点击“验证并检查”。处理环境或文件问题后重新检查。
6. 检查通过后，设置主题后台地址、账号、密码和本站 HTTPS 地址，点击“安装并启用三个主题”。后台地址使用 6–32 位小写字母和数字，以字母开头；密码至少 12 位。
7. 保存成功页面显示的后台地址和账号。密码仅在本次显示，可以点击“隐藏密码”。请将登录资料保存在私密位置。

已有安装再次访问向导时进入维护状态，不重新初始化账号或覆盖配置。安装失败保留原主题选择，可根据提示处理后重试。

系统限制软链接时，安装器会从本机 V10 生成已登记的依赖副本；不写入 V10 核心、默认主题或官方插件源文件。后台改名后，以实际后台地址访问并同步保护规则。

## 更新主题

1. 备份站点，进入主题后台“主题管理 → 安装与更新”。无需卸载主题或重新创建账号。
2. 下载同一份安装合集，在电脑上解压，然后上传其中的 `cra1-theme-install.zip`，不要上传外层教程合集。查看环境、依赖和文件检查结果；有技术阻断时先处理。
3. 由主题超级管理员点击“确认覆盖更新”。全部文件校验后才切换版本，旧主题文件自动备份。
4. 刷新后台及前台，确认新版本加载正常。原配置、未知字段、页面覆盖、账号、密钥、媒体和草稿保留。

首次安装和后续更新使用同一个安装 ZIP，不另外分发更新包，也不提供在线更新。更新器只处理主题自有清单内的文件，拒绝核心、默认主题、官方插件、私有数据、路径穿越、软链接和不可变资源重写。已有安装不应在服务器直接解压覆盖。

## 失败恢复与回退

预检失败不修改站点；写入失败会尝试恢复主题文件。进程中断时，在“主题管理 → 备份与回退”点击“恢复中断更新”。恢复完成后重新检查。

成功更新后，可回退当前更新的界面和资源引用。配置及业务数据保留，较新的安全后端保留，旧资源继续可访问。更新后自行修改过的主题文件可能阻止回退，请先备份处理，避免覆盖修改。

## V10 或模块更新

按 V10 正常流程备份和升级，再进入主题管理点击“重新检查”。检查只读，不改系统文件、数据库模式或主题配置。发现接口或文件不匹配时，使用适配该版本的主题安装包；不要用旧核心覆盖新版系统。
