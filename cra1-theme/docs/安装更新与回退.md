# 酷锐A1主题安装、更新与回退

## 首次安装

1. 下载并在电脑上解压主题合集，打开“安装教程”查看图文步骤。安装前备份网站；当前适用于智简魔方 V10 10.7.4。
2. 将其中的 `cra1-theme-install.zip` 上传到 V10 网站根目录并解压，同名文件夹合并。这一层应能看到 `config.php`、`vendor/` 和 `public/`。
3. 解压后，`cra1-theme/`、`lib/`、`bin/` 位于网站根目录；官网在 `public/web/cra1/`，会员中心、购物车及会员首页分别位于 `public/clientarea/template/`、`public/cart/template/`、`public/home/template/` 下的 `pc/cra1/` 和 `mobile/cra1/`。共用组件、后台与安装器分别为 `public/cra1-shared/`、`public/cra1admin/` 和 `public/cra1-install/`。
4. 在同一浏览器登录本站 V10 超级管理员，打开 `https://你的域名/cra1-install/`，点击“验证并检查”。向导只检查 PHP、必要扩展、数据库连接、目录权限、HTTPS 和文件访问保护。
5. 检查通过后，填写主题后台地址、账号、密码和本站 HTTPS 地址，点击“安装并启用三个主题”。
6. 保存成功页面显示的后台地址、账号和密码，点击“进入主题后台”。主题账号与 V10 系统后台账号独立。

## 已有主题更新

进入主题后台“主题管理 → 安装与更新”，上传合集内的 `cra1-theme-install.zip`。检查通过后点击“确认覆盖更新”，按提示验证主题后台密码。

更新保留配置、账号、图片、草稿、页面内容及业务数据，无需卸载。已有安装通过主题后台更新，不要在服务器直接解压覆盖。

## 回退

在“主题管理 → 备份与回退”选择可恢复版本。若上次更新中断，先点击“恢复中断更新”。回退保留配置及业务数据。
