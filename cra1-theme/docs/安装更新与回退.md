# 酷锐A1主题安装、更新与回退

## 首次安装

1. 下载主题安装包 ZIP，按在线图文教程操作。安装前备份网站；当前适用于智简魔方 V10 10.7.4。
2. 将主题安装包 ZIP 上传到 V10 网站根目录并解压，同名文件夹合并。这一层应能看到 `config.php`、`vendor/` 和 `public/`。
3. 解压后，`cra1-theme/` 位于网站根目录，主题辅助程序包含在其中；官网在 `public/web/cra1/`，会员中心、购物车及会员首页分别位于 `public/clientarea/template/`、`public/cart/template/`、`public/home/template/` 下的 `pc/cra1/` 和 `mobile/cra1/`。共用组件、后台与安装器分别为 `public/cra1-shared/`、`public/cra1admin/` 和 `public/cra1-install/`。
4. 在同一浏览器登录本站 V10 超级管理员，打开 `https://你的域名/cra1-install/`，点击“验证并检查”。向导只检查 PHP、必要扩展、数据库连接、目录权限、HTTPS 和文件访问保护。
5. 检查通过后，填写主题后台地址、账号、密码和本站 HTTPS 地址，点击“完成安装”。安装保留当前主题选择。
6. 保存成功页面显示的后台地址、账号和密码，点击“登录主题后台”，输入自己设置的账号和密码，先配置三个主题的内容。主题账号与 V10 系统后台账号独立，主题未启用也可以编辑和保存。
7. 内容准备好后，再到 V10 系统后台的主题设置中手动选择需要启用的主题，同时核对手机端和会员首页设置。

## 已有主题更新

进入主题后台“主题管理 → 安装与更新”，直接上传主题安装包 ZIP，无需解压。检查通过后点击“确认覆盖更新”，无需再次输入主题后台密码。旧版后台首次升级按旧版提示完成，刷新后使用新流程。

浏览器上传较慢时可展开备用的服务器本地导入，将 ZIP 放到网站根目录下的 `runtime/cra1_theme/distribution/imports/`，上传完成后刷新列表、选择文件并导入检查，再确认更新。原 ZIP 保留，不会自动应用。

更新保留配置、账号、图片、草稿、页面内容及业务数据，无需卸载。日常使用后台上传更新。

### 备用：解压覆盖后完成更新

1. 先备份网站文件和数据库，将同一份完整安装 ZIP 解压至 V10 网站根目录，同名目录合并、同名文件覆盖；不要删除原主题目录、旧资源或用户数据。
2. 在同一浏览器登录本站 V10 超级管理员，访问 `https://你的域名/cra1-install/`，点击“验证并检查”。
3. 检测到已有安装后，勾选已备份，点击“完成更新”。沿用原主题后台地址和账号，不重新初始化。
4. 完成后刷新前台与后台。配置、菜单、账号、密钥、图片、草稿和主题启用状态保留。

只解压还没有完成更新。文件不完整须重新完整解压同一份安装包；超时后先检查当前状态。未完成的事务可在此入口先恢复，再检查更新。事务恢复及版本回退不能找回解压前已覆盖的文件，完整恢复须使用解压前的网站备份。

## 回退

在“主题管理 → 备份与回退”选择可恢复版本。若上次更新中断，先点击“恢复中断更新”。回退保留配置及业务数据。
