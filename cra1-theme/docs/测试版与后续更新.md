# 酷锐A1主题使用与后续更新

当前包版本以 `cra1-theme/release.json` 为准；已安装版本可在主题后台“主题管理”查看。官网、会员中心和购物车平级，独立保存配置和自定义代码。

首次部署使用安装 ZIP；后续使用更新 ZIP，在“主题管理 → 安装与更新”上传并应用。无需 Node、重新安装或重新创建后台账号。操作步骤见《安装更新与回退》。

更新保留配置、账号、密钥、媒体、草稿和页面覆盖。兼容检查只读，列出环境及文件问题；未知版本或原生文件不匹配时，先处理对应问题，再更新主题。V10 与模块继续通过官方流程更新。

更新中断后进入“备份与回退”恢复；成功更新可回退当前更新的界面与资源引用。回退保留业务数据、已保存配置和较新的安全后端。
