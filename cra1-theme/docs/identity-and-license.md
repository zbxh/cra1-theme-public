# 发行标识与许可证维护

当前产品信息以 `product-identity.json` 为统一登记表，构建前运行
`python3 cra1-theme/scripts/identity-audit.py`。仓库根 `LICENSE` 与
`cra1-theme/LICENSE.txt` 必须字节一致，许可证修订版本和摘要登记在
`repository-license.json`。许可仅保留于仓库及源码包，不进入运行清单、
客户安装包、安装器或后台法律说明；历史发行内容不改写。

正式名称为酷锐A1主题，英文 CRA1，目录与主题标识 `cra1`，发行产品
`cra1-theme`，PHP 命名空间 `CRA1\Theme`，JavaScript 接口 `CRA1Shared`，
会员接口前缀 `/console/v1/cra1-theme/`，会话 Cookie `CRA1THEMEID`。

以下名称须保留，不能全局替换：

- V10 原生业务契约，例如 `mf_cloud`、`CloudController`、`CloudLogic`。
- 商品名称、模块类型和图标集合中的 cloud；商家自行填写的网站名称和版权。
- 既有持久配置键、账号名及有数据迁移用途的受限兼容字段。
- 历史不可变发行版、历史安装包的原始说明、许可证及校验值。

第 3 版许可证属于源码可见商业许可证。整个运营主体自然季度的全部业务
营业收入尚未触发时不超过 100,000 元可免费商用；超过后有连续 90 个自然日
补办期，跨季度和短暂回落不重置。触发后，只有一个已结束的完整自然季度
收入低于 80,000 元才恢复免费资格，正好 80,000 元不满足。转售、转授权和
收费分发衍生主题须事先另行授权。完整权利义务以 `LICENSE.txt` 为准。

程序不采集营业收入、不远端激活、不使用授权水印，不因未登记凭证停用页面。
第三方依赖保留各自许可；现有素材来源记录中的未核验状态不会被改为已授权。
