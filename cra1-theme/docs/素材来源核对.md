# 素材来源核对

已核对图标导入代码、固定版本的上游包、许可原文及实际发布文件。1,910 份图标与派生文件的精确路径、SHA-256、来源和许可登记于 `asset-rights.json`；上游包完整性及许可校验值见 `icon-source-evidence.json`，署名和许可原文见 `licenses/icons/`。

核对包含历史导入时的 14 个 Iconify 图标集，以及 Feather、Lucide 原始 SVG。只接受绘图树或精确坐标匹配，记录缩放容器、颜色、序列化及路径分组修改；不将外观相似作为来源证明。`scripts/icon-rights.py` 可使用已下载且完整性校验通过的上游包离线复核，结果必须输出到站外新目录。

开发者已说明方案等内容为自行开发设计，现有实现和布局按自有代码处理。该说明没有把每张历史二进制图片逐一对应到生成记录，因此未用它批量批准所有图片。

旧站根据尺寸、颜色和外部地址产生的图标缓存，以及商家导入图标，不进入安装、更新或源码包；既有安装中的缓存继续保留。默认模板和配置没有直接引用这批缓存，标准图标从固定的共用图标库读取。

当前仍有 153 个随候选运行包交付的素材未完成来源核对：118 个 SVG、1 个 PNG、17 个 JPEG 和 17 个 WebP，涉及旧会员字体的派生图标、部分内置图标、地图、横幅、产品与方案参考图片及主题缩略图。最终包内 `asset-inventory.json` 列出逐文件校验值和状态。

现存开发会话中找到的配图记录主要是已有图片的引用、配置和格式转换，未找到可对应这些历史图片的完整原始下载或生成记录。未确认项继续阻断商业发行，保留现有外观，未自动删除或替换线上素材。后续可按文件补齐来源，或由开发者提供可再分发的替代素材，再重新构建与验收。

第三方开源许可与自有商业许可分别适用。品牌图形的开源许可不代表品牌背书或将他人商标用作自有品牌的授权。
