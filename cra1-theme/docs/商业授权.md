# 商业许可与离线凭证

自有代码按根许可证 [LICENSE.txt](../LICENSE.txt) 提供：非商业学习、测试和二开免费，符合下述条件的商业使用也免费。第三方许可和权利不变。

## 免费商用与授权门槛

按**整个实际运营主体的全部业务营业收入**计算，不能按网站、域名、项目或部门分别计算，也不以利润代替营业收入。收入按依法适用的财务规则确认，以人民币金额判断。

自然季度为每年的 1–3 月、4–6 月、7–9 月、10–12 月。

| 情况 | 使用规则 |
|---|---|
| 非商业学习、测试和二开 | 免费，遵守许可证及第三方声明 |
| 尚未触发授权要求，当季收入不超过 100,000 元 | 可免费商用，无需申请或导入凭证 |
| 当季累计收入超过 100,000 元 | 触发商业授权要求，从超标之日起有 90 个自然日补办 |
| 超标后尚未恢复免费资格，包括季度收入回落至 80,000–100,000 元 | 继续需要商业授权，宽限期不重置 |
| 触发后一个已结束的完整自然季度收入低于 80,000 元 | 自该季度结束后恢复免费商用资格 |
| 主题转售、转授权、收费分发衍生主题 | 不适用免费额度或补办宽限期，须事先单独授权 |

90 天宽限期内可继续正常使用；须在期满前补办授权，或在期满前按完整季度的恢复条件恢复免费商用资格。宽限期跨季度连续计算，同一授权要求下再次超标、更换网站或收入回落均不重启计时。

恢复免费资格以后，再次超过 100,000 元时重新触发门槛及 90 天宽限期。恢复资格不免除此前已经发生的违约或侵权责任，不自动产生已付授权费用的退款权利，也不包含免费商业支持。

例如：

- 尚未触发授权要求时，当季收入正好 100,000 元可以免费商用；达到 100,000.01 元即触发要求。
- 超标后，下一完整季度收入正好 80,000 元仍需授权；该季度收入为 79,999.99 元时，可在季度结束后恢复免费资格。
- 10 月超标后，不能在次年 1 月仅凭新季度收入暂为零认定已恢复。须有触发后已结束且收入低于 80,000 元的完整季度。
- 宽限期满仍需授权且未取得授权的，期满后的持续商业使用不在许可范围内，发行方可依法维权；此前合法免费使用及宽限期内的合法使用不追溯认定违规。

这是**源码可见商业许可证**，不属于 OSI 标准开源许可证。非商业源码和补丁分享按许可证执行；免费商用额度和默认商业部署授权均不包含主题转售或转授权。

## 程序行为与离线凭证

免费资格由使用者按许可证自行判断，程序不采集或上传营业收入，也不根据收入自动限制页面运行。无远端激活、代码加密、运行水印或不可删除标记。授权凭证只记录与核验范围，不影响页面运行；未登记凭证不代表不符合免费使用条件。

发行方在离线非公开目录生成 Ed25519 密钥：

```bash
php cra1-theme/scripts/license.php keygen /私有目录/issuer-secret.json /私有目录/issuer-keys.json issuer-main
php cra1-theme/scripts/license.php sign /私有目录/issuer-secret.json /私有目录/授权输入.json /私有目录/授权凭证.json
```

使用 `licenses/authorization-template.json` 填写主体、站点源地址、商业范围、编号与日期。只有公钥文件可以进入 `cra1-theme/licenses/issuer-keys.json`。私钥永远不能放入主题包或客户站点。此轮不生成代表真实客户的凭证，也不替发行方确定法律主体。

许可及授权资料仅在源码仓库维护，不进入安装向导、主题后台、运行接口或客户安装和更新包。程序不读取凭证来控制运行。

本次修订适用于随本版许可证提供的源码及后续发行包。既有下载包及其校验记录保持原样，不将本次源码修改描述为旧包已更新。

依赖版本、许可标识和已采集许可原文见 `licenses/dependency-inventory.json`。当前运行时依赖许可原文已齐备；素材来源和品牌标识仍须按实际使用逐项核验；候选包会将未核验项目列为阻断项，不能用自有许可证替代这些权利。
