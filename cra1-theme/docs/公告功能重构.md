# 公告功能重构与维护

## 功能范围

公告管理是主题后台的统一辅助入口。官网、会员中心、购物车保持独立配置域，公告通过一份独立的私有文档选择这些主题中的显示页面。

1. **配置与迁移**：登记正式页面和别名，扫描已启用扩展的真实页面；保存整份公告并检查版本冲突。迁移旧官网、会员公告，先备份原值，保留原显示范围。
2. **后台编辑**：复用工作区、草稿、冲突处理、列表拖拽、图标、链接和富文本控件。提供全选主题、分类批量选择、单页选择、搜索、开始和结束时间、优先级、排序及关闭记忆。
3. **三端展示**：共用一个不依赖框架的公告组件。正文与索引透明无外框，标题与简短说明同行；空说明从净化后的正文提取纯文本，仅作用于公开投影，不改写商家原值。索引位于独立关闭按钮左侧；上下箭头切换，单条时箭头保留并禁用，悬停和键盘焦点暂停。详情弹窗显式居中，标题和底部操作固定、正文独立滚动；全部公告桌面左列表右正文，手机列表与详情切换。
4. **旧代码清理**：撤下旧入口表单、Vue 公告组件、Alpine 公告控制器、重复样式、无消费者的默认值和重复构建输入。历史字段只由迁移适配器读取，旧链接映射到公告管理。

## 代码归属

| 位置 | 职责 |
| --- | --- |
| `backend/Announcements/PageCatalog.php` | 三个主题、正式页面、别名和已启用扩展的显示目录 |
| `backend/Storage/AnnouncementStore.php` | 私有存储、校验、版本冲突、整份原子保存和当前页面投影 |
| `backend/Announcements/LegacyMigration.php` | 旧配置和旧浏览器草稿的唯一适配，迁移备份与旧公开数据清理 |
| `backend/Announcements/Endpoint.php` | 动态只读结果，不接受任意配置键，不缓存配置 |
| `source/admin/src/pages/Announcements.jsx` | 统一编辑、页面选择和隔离的草稿预览 |
| `public/cra1-shared/src/announcements.js`、`.css` | 三端实际共用的公告、轮播、详情阅读和关闭记忆 |

官网在公共页头接入，会员和购物车在顶栏组件接入，独立 React 页面由挂载器接入。iframe 中不重复挂载。新的资源只能由统一构建入口生成。

## 数据与迁移

- 正式公告位于非公开的 `runtime/cra1_theme/announcements.json`；旧三份主配置不重写。
- 旧配置原始字节及预置文案依据保存在私有迁移备份中。已核对的旧控制器使用文件指纹识别，迁移其尚未显式保存的首页公告默认值；未知来源和全新安装不推测默认公告。
- 原官网公告仍只作用于首页；原会员全局公告保留会员及购物车范围，原首页公告仍只作用于会员首页。
- 旧浏览器草稿需要管理员点击“恢复旧公告草稿”，检查后再保存；恢复前留存原稿副本，不自动发布。
- 原始旧字段保留作恢复资料；公开快照不再包含旧公告，新公告也不写进静态快照。
- 关闭、未开始、已到期及其他页面的内容在服务端过滤，不注入当前页面或浏览器配置缓存。
- 开始、到期时间按站点时区处理；留空分别表示立即开始和长期有效。
- 顺序和优先级调整不重置用户关闭记忆；内容修改只重置被修改公告的记忆。
- 历史 `hide_single_arrows` 字段仅保留存储兼容；后台撤下该开关，公开结果固定为 `false`，前端始终保留上下箭头。

## 清理规则

删除的是维护中的旧实现。不可变的历史 release、已交付安装包和回退资源不改写。旧配置恢复、旧草稿恢复和深链映射属于仍在使用的兼容代码，不能当作死代码删除。

维护源中的会员外壳样式和官网脚本为唯一输入；旧地址兼容资源由这份源码生成，不再维护另一份副本。

## 验证入口

- `tests/announcements.php`：页面归属、过滤、时刻边界、迁移、预置值、备份、原子保存、冲突与损坏保护。
- `tests/announcements-release.php`：真实更新事务中的迁移、写入中断恢复、回退保留新数据与重新应用。
- `tests/installer.php`：初始化公告，以及安装失败清理新文档。
- `source/admin/tests/announcement-legacy.test.js`：旧草稿筛选、合并和其他未保存编辑的保留。
- `tests/announcements.browser.mjs`：实际构建资源的轮播、暂停、关闭记忆、读取失败、毫秒到期边界、减少动效、编辑保存、预览、冲突、恢复及四档截图。
- `tests/announcements-ui.mjs`：隔离的公告管理全区块、富文本选区和链接、全部下拉框、图标选择、取消及嵌套弹窗键盘行为。

只读预检不能初始化公告、迁移数据或修复快照。回退保留公告新数据和安全过滤；回退到旧界面期间不恢复含旧公告的公开快照，重新应用新版后继续使用同一份公告文档。
