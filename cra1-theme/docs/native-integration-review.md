# V10 10.7.4 现有集成适配审阅

本记录登记已有代码组合，不把本地集成差异描述为官方发行文件。主题仅修改自己的兼容层，保留系统和插件文件。文件指纹来自只读比对，账户、配置和业务数据不进入记录。

审阅范围包括会员鉴权、安全验证、子账号权限、产品归属、续费入口、模块公共接口与模板加载。官方 10.7.4 基线继续独立保留；新增集成必须整组匹配，不能混合不同组合的单个文件指纹，未知修改仍然拒绝敏感操作。

| 差异 | 审阅结果 |
| --- | --- |
| 会员中间件 | 原生 JWT、账户状态、登录有效期校验保留；新增按会话授权及敏感信息过滤 |
| 操作密码 | 委托会话授权服务，清除历史账号级明文缓存；保持 API 请求原契约 |
| 客户模型及共用函数 | 登录随机标识、验证码原子销毁与限次、绑定渠道证明、密码登录限速；销售绑定事务不改变会员接口权限 |
| 产品模型 | 搜索分支统一校验归属；首页恢复期限只用于显式 overview 读取；原生详情归属校验保留 |
| 会员路由 | 同步接口移至认证范围，新增安全及头像接口保留会员认证 |
| 购物车控制器 | 主题及文件名验证、手机模板回退、会员外壳独立解析；不影响支付后端 |
| 云模块 | 原有磁盘失败识别、流量重置时间与 IP SDK 入口；控制器继承关系、原生构造权限和公开方法签名保留 |
| 模块差异边界 | 已有模块未提供应用预装能力；按真实路由与数据表隐藏可选入口，不登记不存在的能力 |

安全组合同时登记新增的授权、验证码、限速、渠道验证、首页补充逻辑及重复提交中间件等依赖，防止只认可调用者而遗漏实际验证服务。模块组合包含实际调用的磁盘状态及流量时间辅助类。

验证使用独立数据库、原生路由及身份校验；外网禁用，云端响应由夹具提供。续费走真实控制器和 ORM；开关机等操作验证到业务边界即停止。账号状态、归属、子账号分组、操作密码挑战、会话隔离、短信一次性验证、未知文件变更及原始基线均需回归。此记录不承诺未安装第三方模块的业务兼容。

2026-10-23 隔离验证：3 个云服务器实例和 1 个物理服务器实例均经完整 HTTP 路由生成新的待付款续费订单；58 项真实原生鉴权及主题守卫检查通过，19 项磁盘与流量原生 ORM 适配检查通过。服务器控制只执行到守卫后的哨兵，不触发真实控制器；云端模块响应使用夹具，不连接服务商。正式业务数据未参与写入测试。
