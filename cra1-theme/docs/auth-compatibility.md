# 登录、注册与第三方登录兼容修复

主题按 V10 原生接口实现登录、注册、找回密码与 OAuth 关联功能。保留主题页面布局与样式，不修改核心、default 或官方插件。

| 问题 | 处理 |
| --- | --- |
| OAuth 授权尚未完成就读取 token，原生服务清除待处理会话 | 跟随官方主题，在授权窗口关闭后读取一次结果；处理取消、弹窗拦截、十分钟过期及过时响应 |
| 首次授权与已有账号绑定结果混淆 | 登录 JWT、进入关联页、账户绑定后重新读取状态分别处理；返回地址限定同源关联页 |
| 扫码优先或无普通登录方式时隐藏其他入口 | 分开渲染账号表单、扫码、动态 OAuth 平台、语言与外部入口；二维码唯一方式也能显示 |
| 原生异常登录响应不包含主题扩展的图形验证字段 | 使用服务端页面投影中的安全验证码策略；图形验证完成后再发送邮件或短信验证码 |
| 停止手机注册导致老用户不能手机找回 | 找回方式按原生邮箱和手机两种能力独立处理 |
| 语言提交字段错误，失败仍刷新 | 按原生 language 字段提交，仅成功后保存语言并刷新 |
| 固定启用记住登录 | 使用官方默认 remember_password=0 |
| 登录强制新密码长度，强密码只提示不检查 | 登录仅要求非空；注册/找回按原生长度、字符组成和连续重复规则校验 |
| 平台图标缺失，登录协议仅被动说明 | 动态展示插件名称和图标；普通账号登录显式勾选协议，链接沿用系统设置 |

## 支持范围

第三方平台列表来自已启用的 V10 OAuth 插件，主题不写死平台名称。以后新增遵循该官方 OAuth 契约的插件可复用此流程；不承诺非标准独立登录插件无需适配。

外部平台的实际授权能力取决于已安装插件及平台设置。手机、邮箱、扫码与实名异常登录中的外部服务由对应 V10 插件和系统配置负责。
