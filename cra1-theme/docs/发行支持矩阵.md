# 酷锐A1主题兼容范围

当前为测试版。已安装的主题版本以主题后台“主题管理”为准，源码版本以 `cra1-theme/release.json` 为准。

| 项目 | 当前测试基准 | 使用说明 |
| --- | --- | --- |
| 智简魔方 V10 | 10.7.4 | 10.7.2 站点先通过官方流程升级 |
| 运行环境 | Nginx、PHP 7.4、HTTPS | 安装向导会检查实际环境 |
| 云服务器模块 | MfCloud 4.3.0 | 支持主题专属产品列表与控制面板 |
| 物理服务器模块 | MfDcim 4.2.1 | 使用对应模块能力；不延伸其他模块的验证结论 |
| 通用商品模块 | IdcsmartCommon 4.3.1 | 保留原生商品及管理流程 |
| 原生插件页面 | 新闻、帮助、认证、工单、子账户 | 沿用已安装插件的接口及权限；具体功能取决于插件状态和版本 |
| 其他系统或模块版本 | 尚待验证 | 不仅凭版本号相近判断兼容 |

主题安装、更新和回退只处理主题自有文件，不覆盖 V10 核心、默认主题或官方插件。原生依赖通过清单登记，安装和更新时核对实际文件；差异或未知契约需先确认，不自动修补系统。

V10 系统与模块继续使用官方升级流程。升级后可在主题后台重新检查兼容性；未知版本不会直接停用整个主题，无法确认安全契约的敏感操作会暂停提交。

原生插件页面依赖与当前 V10 匹配的插件版本。旧插件模板若不符合系统解析规则，应更新相应插件，不通过覆盖系统或默认主题解决。

在线支付、短信及第三方登录仍由对应插件提供。接口模拟检查不能替代每家外部服务的真实业务验证。

安装与更新步骤见 [安装更新与回退](安装更新与回退.md)。
