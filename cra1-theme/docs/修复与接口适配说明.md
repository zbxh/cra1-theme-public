# CRA1 发行工程修复与依赖说明

本文说明主题自有实现与原生接口的职责边界。支持范围见 [兼容范围](发行支持矩阵.md)。

## 实现与原文件边界

| 能力 | 主题实现 | 原生依赖及边界 |
|---|---|---|
| 三个配置域、页面覆盖与公开投影 | `backend/Storage`、`backend/Compatibility/runtime.php` | 保留现有 JSON 路径、未知字段、空值与快照入口；损坏配置禁止覆盖 |
| 启动与依赖缺失隔离 | `backend/bootstrap.php`、官网 `controller/hooks.php` | 使用原生主题钩子；未安装、停用或文件缺失时不牵连其他主题，不匹配 `mycloud` |
| 插件与接口能力检测 | `backend/Compatibility/Capabilities.php` | 启用状态、接口、方法、必要结构分开确认；单项异常不清空其他能力 |
| 安全验证与凭据脱敏 | `backend/Http/MemberGuard.php`、`OperationGuard.php`、`backend/Security` | 保留原生 JWT、权限、产品归属及验证码消费；未知安全契约不提交敏感操作 |
| 原生路由适配 | `backend/Http/Routes.php`、`Http/home/MemberController.php` | 使用 V10 能识别的字符串控制器路由，避免原生分发器对闭包产生类型错误 |
| 头像和首页产品 | `backend/Http/MemberController.php`、`Compatibility/HomeProducts.php` | 主题自有接口；保留导航关联分类与生命周期过滤；不要求核心新增响应字段 |
| 失败磁盘与精确流量时间 | `backend/Compatibility/MfCloudAdapter.php` | 真实官方 MfCloud 4.3.0 父类、ORM 及固定文件契约；删除同时检查归属、失败证据和远端绑定 |
| 未知模块原生页面 | 会员 `js/module-deps.js` 及登记的原生组件 | 去重、正确顺序加载外壳与组件，保留原生回退；不打包 default 或官方模块源码 |
| SEO 文件 | `backend/Support/cra1_theme_seo.php` | robots 仅管理明确标记区块，站点地图独立文件；归属不明或损坏时不覆盖 |
| 安装与后台改名 | `backend/Release/Installer.php`、`public/cra1-install` | 原生超级管理员、同源 HTTPS 与 CSRF；使用原生配置验证器和模型；安装后保留原主题选择，由管理员配置完成后手动启用 |
| 只读兼容与候选预检 | `backend/Release/Inspector.php`、`Manifest.php`、`Package.php` | 检查实际文件字节、模块版本、MySQL 环境和私有路径保护；不隐式写配置、快照或缓存 |
| 更新、中断恢复、回退 | `backend/Release/Updater.php`、`References.php` | 只处理主题清单路径，防路径穿越、软链接和不可变目录重写；最后提交发行指针 |
| 商业凭证 | `backend/Release/LicenseCredential.php`、`scripts/license.php` | 仅源码仓库工具保留；运行包、安装器及后台不提供凭证功能 |

正式源码入口为 `scripts/build.mjs`。运行包包含预构建资源，不要求客户安装 Node。原生依赖按固定清单从客户合法安装中复用，引用及依赖由发行清单逐项登记，并保留已验证组合的对应校验值。主题不修改系统、default、官方模块或其他插件文件。原生文件差异需独立核对，不能仅按系统版本判断兼容。

## 主题会员接口

以下地址使用 `/console/v1/cra1-theme/` 前缀，保留 `{status,msg,data}`。由原生 `CheckHome` 验证登录身份，拒绝匿名、失效令牌、跨站和不适用的 API 身份。权限仍由原生规则及产品归属决定。响应使用 `no-store`，不提供任意配置键读取。

| 方法与相对地址 | 用途 |
|---|---|
| `GET security/operation/status` | 返回是否需要操作验证及本登录的验证有效期 |
| `POST security/operation/verify` | 校验操作密码，签发十五分钟服务端授权 |
| `GET / PUT member/avatar` | 读取或保存当前会员头像 |
| `POST member/avatar/upload` | 上传当前会员头像素材 |
| `GET member/products` | 返回经原生权限过滤的首页产品及生命周期结果，支持分页 |
| `GET member/host/:id/field/:field` | 显式读取密码类型自定义字段，执行权限、归属及附加验证 |
| `GET module/mf_cloud/:id/disk` | 返回磁盘及可靠的失败状态 |
| `GET module/mf_cloud/:id/flow` | 返回包含精确重置时间的流量结果 |
| `DELETE module/mf_cloud/:id/disk/:disk/failed` | 清理已证实创建失败且无远端绑定的磁盘记录 |

服务端授权绑定当前 JWT、账号密码及安全资料；资料改变后失效，不缓存明文操作密码。原生要求短信或邮件验证码的操作沿用其校验和消费流程，不重复消费。普通列表、资料与详情持续脱敏；查看和复制登录信息走显式敏感读取。供应商和内部异常不下发会员页面。

### 权限与数据处理

- 子账户路由规则使用原生登记方式，保留钩子拒绝结果；产品范围取原生分配结果，多个范围相交。空分配返回空列表，不能因原生空参数变成父账户全部产品。
- 产品读取、模块适配、续费、电源、控制、删除和安全组操作按原生权限组及产品归属分别检查；查看凭据不能仅凭操作密码绕过控制权限。
- 原生产品列表会将自定义字段定义和数值行分开返回。普通响应结合字段类型递归移除密码和无法确认类型的数值字段，保留普通文案；首页原生列表同样脱敏。显式密码读取先以 ORM 核对归属，再沿用原生详情权限；原生详情不返回 `client_id`，不能据此误拒合法用户。
- 图形验证码弹窗立即接管取消和 Esc，关闭后恢复焦点并清理计时器；避免原生控件延迟绑定期间取消按钮失效。原生验证码插件未修改。

## 安装和主题管理接口

`public/cra1-install/api.php` 仅提供 `check`、`install`，需要原生超级管理员身份、同源 HTTPS、安装会话与 CSRF。检查运行环境；诊断不确定项提示处理建议，不因未验证的系统版本或普通页面状态码误拒绝安装。安装完成后锁定初始化入口，再次访问进入维护。

独立主题后台使用既有 POST、会话、CSRF 与角色控制，`api.release.*` 提供：

- `check`：运行环境、实际文件状态和兼容诊断。
- `history`：当前发行、历史备份和中断状态。
- `upload`、`candidate.get`、`apply`：候选上传、预检和应用。
- `rollback`、`recover`：回退当前更新或恢复中断事务。
- `local.list`、`local.import`：从指定导入目录选择主题安装包，作为直接上传的备用方式。

管理员可以只读检查；上传、应用、导入、恢复及回退仅超级管理员执行，校验登录会话、CSRF 与请求来源，无需重复输入后台密码。候选绑定账号、会话、校验值和有效期，防止预检后换包。回退保留较新的安全后端，不恢复已关闭内容或旧的泄露快照。
