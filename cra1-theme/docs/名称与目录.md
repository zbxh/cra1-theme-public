# 酷锐A1主题（CRA1）

产品中文名为「酷锐A1主题」，英文品牌为 `CRA1`，发行产品标识为 `cra1-theme`。

官网公共页脚和主题后台底部的主题署名统一为“主题：酷锐A1”，链接到 https://github.com/zbxh/cra1-theme-public ，不附带英文品牌。其他技术标识继续使用上述约定。

三个主题继续平级，独立保存配置和自定义代码。商家的站名、Logo、页面标题及业务内容不自动替换为主题品牌。

V10 的原生主题列表按目录名显示，因此系统中选择 `cra1`，主题缩略图显示完整品牌。主题控制器为 `template\cra1\controller\Cra1`，不修改 V10 核心来改变原生主题列表。

官方 `mf_cloud`、`MfCloud`、`cloudDetail`、`cloudList`、图标库的 `Cloud` 及云图标名称、官网云服务器页面 `cloud.html` 等属于业务契约，保留原名。

已有的 `cloud_menu_text`、`cloud_menu_aside_text`、`cloud_menu` 查询参数及页面专属 `price_slider_cloud_text` 等属于配置或页面数据契约，继续保留，避免已有设置、草稿和导航绑定失效。`mf-cloud`、`m-cloud-m` 是原生模块样式选择器；`marketing-hero-cloud` 等表示雾状云层，均不属于主题品牌。

后台会话仅在读取旧测试版会话时接收历史 `cloud_admin`、`cloud_csrf`，迁入新键后删除旧键；新后端只写 CRA1 键。该兼容不授予额外权限，也不重建账号或主配置。

自有工程的 `package.json` 与锁文件根元数据均指向 CRA1 根许可证；依赖包的 MIT、ISC、Apache 等原始许可不改写。当前源码许可为第 3 版，按完整运营主体自然季度收入判断，超过 10 万元有 90 天补办期，触发后须有一个完整季度收入低于 8 万元才恢复免费资格。
